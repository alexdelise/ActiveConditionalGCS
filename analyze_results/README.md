# Result Analysis

Shared loaders and plotting functions are located directly in this directory.
Notebook groups are:

- [unweighted/main/](unweighted/main/)
- [unweighted/ablation/](unweighted/ablation/)
- [weighted/main/](weighted/main/)
- [weighted/ablation/](weighted/ablation/)

Unweighted notebooks read from
[../results/unweighted/](../results/unweighted/) and write figures to
[../results/unweighted/figures/](../results/unweighted/figures/). Weighted
notebooks use [../results/weighted/](../results/weighted/) and
[../results/weighted/figures/](../results/weighted/figures/).
